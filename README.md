# 🧩 Maze Analyser & Pathfinder Visualizer

A collection of C programming projects focused on maze solving, pathfinding algorithms, and graphical visualization using **C** and **raylib**.

This repository contains a basic maze solver and a graphical maze visualization project, built to strengthen my understanding of algorithms, data structures, and graphics programming.


### Maze Solver & Pathfinding Visualizer

A console-based maze solver implemented in C.

**Features**
- Represents a maze using a text file.
- Uses pathfinding algorithms to find a route through the maze.
- Implements a queue data structure for traversal.
- Separates the program into modular C source and header files.

**Technologies:** C, arrays, queues, pathfinding algorithms.

**Folder:** `Maze solver-pathfinding visualizer/`

### 2. Maze Graphics with raylib

A graphical maze visualization project using raylib.

**Features**
- Opens a graphical window.
- Renders the maze visually.
- Supports keyboard interaction to control the demonstration.

**Technologies:** C, raylib, graphics programming.

**Folder:** `MazegraphicsTest/`

## 🚀 Getting Started

### Prerequisites

- A C compiler such as GCC
- Visual Studio Code or another C development environment
- raylib for the graphical project

### Run the Maze Solver

1. Open the `Maze solver-pathfinding visualizer` folder.
2. Compile the source files using GCC:

   ```bash
   gcc main.c pathfinding.c queue.c -o maze_solver.exe
   ```

3. Run the program:

   ```bash
   ./maze_solver.exe
   ```

### Run the Graphics Project

1. Open the `MazegraphicsTest` folder.
2. Follow the build instructions in its README.
3. Build and run the project using the provided raylib configuration.
